## Codex integration

Use the exact Senior CLI path given by the session hook or resolve it from the installed skill.
Skills are invoked with `$senior:onboard`, `$senior:design`, `$senior:pair`, `$senior:decide`,
`$senior:why`, `$senior:regret`, `$senior:story`, `$senior:fast`, `$senior:replay`, and `$senior:level`.

For hands-on work, use the editor MCP server's guided pieces, checks, questions and narration.
Use the connected server's discovered tool names; their namespace may vary by Codex surface.
The editor owns Type, Accept and Watch, traces, knowledge cards, choices and replays.
If it is disconnected, report its reason and offer chat pairing. Never silently write the
important lines that the user is meant to type. Answer a question and resume the same piece.
When helper tools are available and permitted, prepare the next step with a read-only helper
using `references/navigator.md`. Otherwise prepare it yourself. Do not require a particular model.

Share conclusions and visible evidence rather than private chain-of-thought. Honor the
host's sandbox, approvals and user instructions; Senior grants no additional permissions.
